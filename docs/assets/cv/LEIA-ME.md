# Currículo em PDF

O botão **"Baixar CV (PDF)"** do portfólio aponta para este arquivo:

    docs/assets/cv/rodrigo-dionizio-cv.pdf

## Como publicar o seu currículo

1. Abra <https://github.com/rodrigodionizio/meuportifolio/upload/main/docs/assets/cv>
2. Arraste o seu PDF para a área de upload.
3. **Renomeie o arquivo para exatamente** `rodrigo-dionizio-cv.pdf` (tudo minúsculo, com hífens).
4. Confirme o commit. Em 1–2 minutos o botão passa a funcionar.

> Enquanto o arquivo não existir, o botão leva a uma página 404 do GitHub Pages.
> Suba o PDF assim que possível — é o primeiro item que um recrutador procura.
