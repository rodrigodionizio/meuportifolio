# Como publicar o README do perfil

O `README.md` desta pasta é o **README de perfil do GitHub** — aquele que aparece em
<https://github.com/rodrigodionizio> logo abaixo da sua foto. Hoje ele não existe, e o
perfil chega vazio para quem visita.

Para ele funcionar, precisa morar num repositório **com exatamente o mesmo nome do seu
usuário**.

## Passo a passo (5 minutos, pela web)

1. **Crie o repositório**
   Abra <https://github.com/new> e preencha:
   - **Repository name:** `rodrigodionizio` — exatamente assim, igual ao seu usuário
   - **Public** (obrigatório: o GitHub ignora README de perfil em repositório privado)
   - marque **Add a README file**

   Ao digitar o nome certo, o GitHub mostra a mensagem
   *"You found a secret! rodrigodionizio/rodrigodionizio is a special repository…"*.
   É o sinal de que está correto.

2. **Envie o banner**
   No repositório recém-criado: **Add file → Upload files**, e suba o `banner.png`
   desta pasta. Confirme o commit.

3. **Cole o conteúdo**
   Abra o `README.md` do repositório, clique no lápis (**Edit**), apague o conteúdo
   inicial e cole todo o conteúdo do `README.md` desta pasta. Confirme o commit.

4. **Confira**
   Acesse <https://github.com/rodrigodionizio>. O README aparece abaixo do seu perfil.
